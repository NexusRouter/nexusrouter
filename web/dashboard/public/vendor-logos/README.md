# Vendor logos

SVG icons for model library vendor rows (`/vendor-logos/<vendor_code>.svg`). Referenced by gateway seed data (`logo` field) and dashboard `VENDOR_LOGO_FALLBACK`.

## Sources

- **Simple Icons** (CC0 1.0): vendor brand SVGs copied from the [`simple-icons`](https://github.com/simple-icons/simple-icons) npm package (various versions via jsDelivr), including but not limited to OpenAI-classic builds, Anthropic, Google, Mistral AI, DeepSeek, Moonshot AI, MiniMax, Baidu, Alibaba Cloud, ByteDance, Cloudflare, Replicate, Microsoft Azure (legacy package path `microsoftazure`), QQ (Tencent ecosystem proxy for Hunyuan).
- **Project placeholders**: `groq.svg`, `cohere.svg`, `zhipu.svg`, `baichuan.svg`, `novita.svg`, `together.svg`, `xai.svg` are minimal monogram tiles (not third-party marks) where Simple Icons had no suitable icon or license coverage.

Third-party marks remain property of their owners; use only for product identification in the admin UI.

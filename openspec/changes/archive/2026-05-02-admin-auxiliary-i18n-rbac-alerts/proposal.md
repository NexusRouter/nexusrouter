## Why

管理控制台已具备上游、密钥、进阶安全与日志等能力，但面向运维与多角色团队时仍缺少：**中英双语**以降低协作成本、**系统设置**集中展示与持久化网关关键参数、**角色权限**避免误改生产配置，以及**可配置阈值的运行态告警**，以便在异常时第一时间在面板内可见。

## What Changes

- **国际化（i18n）**：仪表盘支持 **中文（默认）** 与 **英文** 切换；所有管理页文案、表单标签、`message` 提示、空态与错误提示均走资源键，无硬编码单语混用。
- **系统设置**：新增「系统设置」能力，集中展示并可编辑网关基础信息（**监听端口**、**日志输出路径**、与请求相关的 **超时** 等；**缓存时长** 若当前架构无独立缓存层则作为「预留/文档化」项或与现有 Redis 配置对齐，见 `design.md`）。保存策略：**写回配置文件或环境模板 + 提示需重启**；可选实现 **SIGHUP / 子集热重载**（与现有 `reload-config` 对齐），**监听端口变更** MUST 明确为「需进程重启」。
- **权限管理（RBAC）**：引入至少 **`admin`（管理员）** 与 **`operator`（操作员）** 两角色；JWT 或会话载荷携带 **`role`**；管理 API 与前端路由按角色鉴权：**操作员** 可查看仪表盘指标、访问日志、接口调试等只读能力，**MUST NOT** 调用修改类配置/密钥/安全策略的写接口（返回 **403**）。
- **异常告警**：基于现有或扩展的指标（上游可用性、网关/代理错误率等），在管理布局内提供 **可配置阈值** 的告警条/徽章；超阈值时 **视觉突出**（颜色、图标），并记录触发原因摘要（不含敏感数据）。

## Capabilities

### New Capabilities

- `admin-i18n`：仪表盘语言包、切换器、与 Ant Design `locale` 联动；默认 `zh-CN`。
- `admin-system-settings`：系统设置 API 与 UI；参数模型、持久化边界、重启/热更新说明。
- `admin-rbac`：角色模型、登录签发、管理 API 中间件、前端菜单与按钮级禁用。
- `admin-runtime-alerts`：告警阈值配置、指标评估周期、面板内告警展示与清除/静音（可选）。

### Modified Capabilities

- `dashboard-frontend`：在保留既有工程约束的前提下，扩展「用户可见文案」为 i18n；新增设置页、告警条、角色可见导航。
- `gateway-backend`：管理 API 增加设置读写、RBAC 声明与校验、告警状态/阈值端点（与指标模块集成）。

## Impact

- **前端**：`web/dashboard`（新 `locales/`、`i18n` 封装、布局与页面改造、`package.json` 可能增加 `i18next` 等依赖）。
- **后端**：`services/gateway`（`internal/config`、`internal/adminauth`、管理路由中间件、`internal/metrics` 或聚合层、可选新 YAML 段 `admin_alerts` / `system_settings`）。
- **运维**：端口与路径类变更涉及重启或 reload 文档；多用户需预置或迁移角色数据（见 `design.md`）。
- **兼容性**：默认行为保持「单管理员 + 中文」等价体验；新增环境变量或配置文件字段 MUST 向后兼容（缺省等价于当前行为）。

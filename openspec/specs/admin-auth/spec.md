## Requirements
### Requirement: 管理员登录与会话令牌

系统 MUST 提供管理员**账号与密码**认证；验证成功后 MUST 向客户端返回**权限令牌**（或等价的已认证会话），使后续管理 API 请求可被识别为已授权。令牌 MUST 具备**过期**语义；登出或过期后 MUST 无法继续访问需认证的管理能力。

#### Scenario: 凭据正确则颁发令牌

- **WHEN** 客户端提交与配置一致的管理员用户名与密码
- **THEN** 响应包含有效权限令牌（或设置安全 Cookie），且后续携带该凭证的管理请求通过认证

#### Scenario: 凭据错误则拒绝

- **WHEN** 客户端提交错误密码或未知用户名
- **THEN** 响应为 **401**（或 **403**，实现固定其一并文档化），且 MUST **不**颁发有效权限令牌

### Requirement: 未认证访问受保护管理界面

管理控制台中标记为受保护的页面与路由 MUST 在**未持有有效权限令牌**时将用户**重定向至登录页**（或等价拦截），且 MUST **不**展示需授权的数据。

#### Scenario: 未登录访问仪表盘

- **WHEN** 用户直接打开受保护路由 URL 且本地无有效会话/令牌
- **THEN** 应用导航至登录页

### Requirement: 记住密码与客户端持久化

登录界面 MUST 提供「记住我」或等价选项。实现 MUST **禁止**以明文形式将用户密码持久化到 **localStorage**；允许持久化**用户名**与非敏感偏好。若启用「记住我」，MUST 通过**延长会话/刷新策略**实现，具体机制在 `design.md` 固定。

#### Scenario: 未勾选记住我

- **WHEN** 用户未勾选「记住我」并成功登录
- **THEN** 浏览器关闭后会话在实现定义的合理时间内失效或需重新登录（与勾选分支可区分）

### Requirement: 忘记密码流程

系统 MUST 提供「忘记密码」入口。若运维配置了邮件/外部重置能力，MUST 支持一次性重置链接或验证码流程；若未配置，MUST 向用户展示明确说明（如联系管理员）并 MUST 在运维文档中提供**受控重置**方式（如 CLI 或更新配置）。

#### Scenario: 未配置邮件时仍可发现路径

- **WHEN** 未配置邮件相关环境变量
- **THEN** 用户仍能看到「忘记密码」引导且不会进入无限加载或空白错误页

# 网关：可选工作目录 `.env` 本地环境文件

## 功能说明

API 进程在初始化配置之前，尝试从**当前工作目录**读取 **`.env`**（dotenv 格式），将其中键值合并进进程环境。文件不存在或不可读时不报错、不影响启动。

已存在于操作系统环境中的变量**不被** **`.env`** 覆盖，便于容器与 CI 继续用标准注入方式优先生效。

## 实现要点

- 在 **`cmd/api/main.go`** 入口最早阶段调用 **`config.LoadDotEnv()`**；无 **`.env`** 或打开失败时立即返回。
- **`LoadDotEnv`** 仅对当前环境中仍为空的键调用 **`os.Setenv`**；已有非空取值的键不覆盖。
- **`internal/config.Load`** 仍通过 Viper 读取 **`NEXUSROUTER_*`** 等键；与 **`.env`** 组合时行为与仅使用 OS 环境变量一致。

## 兼容性

- 未提供 **`.env`** 时行为与此前完全一致。
- 生产部署可继续仅使用环境变量或编排注入，无需 **`.env`** 文件。

# 网关：入口命令行 `-help` / `-h`

## 功能说明

API 进程在加载 **`.env`**、初始化依赖与监听端口之前，若命令行包含 **`-help`** 或 **`-h`**（二者等价），则向标准输出打印简短用法（可执行文件名、**`-version`** 与帮助类选项说明），并以退出码 **0** 结束，不启动 HTTP 服务。

若同时传入为真的 **`-version`**，则优先按 **`-version`** 仅输出一行版本字符串。

解析失败（例如无法识别的标志）时向标准错误输出说明并以非零码退出，与 Go **`flag`** 包惯例一致。

## 实现要点

- 在 **`cmd/api/main.go`** 中于 **`config.LoadDotEnv()`** 之前完成解析与输出；与 **`-version`** 共用同一套预解析逻辑，避免重复启动服务。

## 兼容性

- 未传递 **`-help`** / **`-h`** 时启动流程与此前一致。
